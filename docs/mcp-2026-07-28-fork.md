# MCP 2026-07-28 only (fork)

This fork makes REA serve **only** MCP `2026-07-28` (stateless), with no
2025-era `initialize` fallback.

## Changes

- `src/server/protocolVersions.ts`
  - `MODERN_PROTOCOL_VERSIONS` is the only list a production endpoint uses.
  - `DEFAULT_SUPPORTED_PROTOCOL_VERSIONS` keeps the SDK-era revisions for
    embedded `createServer` callers and in-memory tests.
- `src/main/transport.ts`, `src/main/deferredRuntime.ts`
  - Every production stdio/HTTP server is constructed with
    `supportedProtocolVersions: MODERN_PROTOCOL_VERSIONS`.
- `src/server/http/serveStreamableHttp.ts`
  - `/mcp` is served by `createMcpHandler(..., { legacy: "reject" })`.
  - Modern requests (`MCP-Protocol-Version: 2026-07-28`, `Mcp-Method`,
    `Mcp-Name`, `_meta`) are per-request and stateless.
  - 2025-era `initialize`/session traffic is rejected with
    `-32022 Unsupported protocol version` naming `["2026-07-28"]`.
  - The legacy `McpSessionSlot`/`LiveSession` adapter, its single-instance
    handover, session ids and 2025 test doubles are removed. Each request's
    instance drains its tool handlers before REA's provider hooks run.
- `src/main.ts`
  - stdio uses `serveStdio(factory, { legacy: "reject" })`.
- `src/mcpDoctor.ts`
  - the doctor client pins `2026-07-28`; the check is named
    `server/discover`.
- `src/main/eagerRuntime.ts`
  - `rea mcp --http` refuses `REA_MCP_TOOL_CATALOG_PROFILE=hot-cold`, because
    the stateless modern transport has no connection to keep a catalog loaded.
    `full` and the stdio transport remain supported.

## Verification

```bash
# Node pinned by .nvmrc (24.22.1)
nvm use

node scripts/rea.mjs mcp doctor
# server.protocol_version: 2026-07-28
# tools: 268/268

node scripts/rea.mjs mcp --http --port 18799

curl -i -X POST http://127.0.0.1:18799/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'MCP-Protocol-Version: 2026-07-28' \
  -H 'Mcp-Method: server/discover' \
  --data '{"jsonrpc":"2.0","id":1,"method":"server/discover","params":{"_meta":{"io.modelcontextprotocol/protocolVersion":"2026-07-28","io.modelcontextprotocol/clientInfo":{"name":"test","version":"1"},"io.modelcontextprotocol/clientCapabilities":{}}}}'
# 200, supportedVersions ["2026-07-28"]

# Legacy initialize is rejected:
curl -i -X POST http://127.0.0.1:18799/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  --data '{"jsonrpc":"2.0","id":2,"method":"initialize","params":{"protocolVersion":"2025-11-25"}}'
# 400, error -32022 Unsupported protocol version: 2025-11-25
```

## Notes

- The 268-tool catalog is unchanged; only the MCP framing/lifecycle changed.
- `Mcp-Session-Id`, the HTTP GET stream, SSE resumability and `initialize`
  are not served.
- Clients must support MCP `2026-07-28` (`server/discover`, per-request
  `_meta`, `Mcp-Method`/`Mcp-Name`).
